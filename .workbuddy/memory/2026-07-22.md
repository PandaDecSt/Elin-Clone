## ⚠️ 解析 .assets 会在 C 盘留 ~704MB 临时文件
- UnityPy/TypeTreeGenerator 读游戏 `Elin_Data`（磁盘资源共 2.6GB：resources.assets 73.8MB / resources.assets.resS 1462MB / sharedassets0.assets 548MB / sharedassets0.resource 302MB 等）时，往 `C:/Users/PandaDecSt/AppData/Local/Temp` 物化资源留下 3 个 `.tmp`：`077db4f6-…-.tmp`(417MB)、`95c75e68-…-.tmp`(275MB)、`84d5c277-…-.tmp`(11.5MB)，合计 ≈704MB。
- **机制澄清**：UnityPy 不是"一定"写 Temp——未压缩 `.assets`/`.resource` 原地读不写；仅在遇到**块压缩/LZ4 或 AssetBundle/压缩容器**、需要可寻址副本时才落 Temp。Elin 资源体量大 → 几乎必出。
- **重要修正（2026-07-22 13:15）**：这 3 个 `.tmp` 当前被**操作系统锁着**（读即 `PermissionError: 拒绝访问`，非解析进程持有——当前 18 个 python 进程全是 `python -m http.server` 开发服务器，与解析无关）。锁源疑为 Windows Defender 实时扫描或 pending-delete，**当下不可删**，需等锁释放（杀软扫完/重启）后再清。之前称"孤儿文件可随时删"不准确。
- **避免 C 盘掉空间的办法**：UnityPy 用 `tempfile` 模块、认 `TEMP`/`TMPDIR` 环境变量。下次跑解析前 `set TEMP=D:\tmp && set TMP=D:\tmp`，临时文件即落 D 盘。或跑完顺手清 Temp（重启后更稳）。
- 注：TypeTreeGeneratorAPI 包装进 C 盘 venv ≈20.6MB；pip 缓存 363MB 是项目长期累计、非本次单独产生。项目产出全在 D 盘(<60KB)。
