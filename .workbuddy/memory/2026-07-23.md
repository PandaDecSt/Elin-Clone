## 修复 2 边墙体"自动拐弯衔接"不跟随邻居的 bug
- 现象：先放一面孤立墙(默认 se)，再在其北边/西边补墙，原墙不朝邻居改朝向（南北墙南端不朝南、被西/北邻居包围的格子不朝南），衔接断裂。
- 根因：`_reconcileWallAt` 孤立分支原 `need.add(safeAx || fallback)` 让 `safeAx`(已有墙轴向) 优先于 `fallback`(基于邻居的封口朝向)，导致已有墙格永远沿用旧轴向、不跟随新邻居。
- 修复：有墙邻居(hasN/hasW)时强制用 `fallback`(北邻→sw、西邻→se) 跟随对齐；仅真孤立(无任何墙邻居)才保留 `safeAx` 或 R 键朝向。仍是 2 边缘 se/sw 系统(用户此前要求删 nw/ne)。
- 验证：写 Playwright 测试 `test_wall2.mjs`(managed node + Edge @8123)，dump T1 孤立/T2 东西向/T3+T4 南北向双向/T5 拐角/T6 拆墙自愈/T7 西北邻居，修前 T4.C=[se]、T7.A=[se] 错误，修后全 PASS([sw,sw,sw]、A=[sw])。

## 重写墙体模型：原生固定 + 仅增量补/删 auto 面（用户纠正的根本设计）
- **用户指出的根本错误**：之前 `_reconcileWallAt` 每次按四邻重算 `need` 并重建墙列表，导致原生方向被邻居覆盖（放 se、南边一来墙就把这格改成 sw=翻面），且同向墙也可能被翻 → 违背"一排同向墙不可能有拐弯"。
- **正确模型（用户定义，必须遵4条）**：
  1. 每格最多 1 面「原生墙」(original)，方向 = 放置时 R 键朝向(se/sw)，**永远不变**，自动衔接绝不改它。
  2. 拐弯 = 在缺口边「增量补」(auto:true) 一面墙：原生方向 + 垂直邻居方向 → 补出另一面，单格可有 2 面墙才形成拐角。
  3. 补墙只增不删原生；拆墙时只删「补出来的那面」(auto)，原生保留。
  4. 一排同向墙：没有垂直邻居 → 不补 → 不可能有拐弯。
- **实现**：墙体条目新增 `auto:true` 标记补充面，原生条目无此标记（旧存档裸 number/对象视作原生）。
  - 新建格：`originals.push({id, axis: buildMode.wallAxis})`。
  - 原生 se → 仅当【南邻】有墙补 `sw`；原生 sw → 仅当【东邻】有墙补 `se`（垂直邻居才补，绝不改原生）。
  - 西/北邻居不反向长边（无上缘精灵），由对方用 se/sw 接住。
  - 组装 = 非墙 + 原生(不变) + `needAuto` 中需要的面（复用已有 auto 条目，原生已覆盖则跳过）。
  - 拆墙：本格+四邻重算 → 邻居的 auto 面在 needAuto 不再包含时自然消失，原生永留。
- **验证**：`test_wall3.mjs`(Edge @8123) 四场景全 PASS：rowEW=[se,se,se]、rowNS=[sw,sw,sw]、cornerA=[se,sw]&B=[se]、afterRemove=[se]、eastNeighborA=[se](不翻面)。
- 仅改 `js/game.js` 的 `_reconcileWallAt`（doc+实现），`iso.js`/预览无需改（auto 条目 axis 仍 se/sw，`drawBlockStack` 忽略 auto 字段）。

## 修复：一排平行（同向）墙被误补成假拐角
- **用户反馈**："一排平行的墙也不会触发补墙" —— 之前补墙条件只看"南邻/东邻有墙"，不区分邻居是同向(平行)还是垂直(拐角)。结果两排同向墙上下相邻时，上排每格被误补 sw，变成假拐角，违背"同向不可能拐弯"。
- **根因**：`_reconcileWallAt` 的 `needAuto` 用 `wallAt(gx,gy+1)` / `wallAt(gx+1,gy)`（只要邻格是墙就补），未判断邻居朝向。
- **修复**：新增 `nativeAxisAt(x,y)` 取邻居的**原生**轴向（跳过 auto 补面）；补墙改为**仅当垂直邻居(朝向不同)**才发生：
  - 原生 `se` → 仅当【南邻原生是 `sw`(朝南)】才补 `sw`；
  - 原生 `sw` → 仅当【东邻原生是 `se`(朝东)】才补 `se`。
  - 同向(平行)邻居 → 不补（如 A(0,0)se 与下方 B(0,1)se：B 是 se 平行 → A 不补，A=[se] 而非旧逻辑 [se,sw]）。
  - 删除了不再使用的 `wallAt` 死代码。仍是 2 边缘 se/sw 系统。
- **验证**：`test_wall4.mjs`(Edge @8123) 全 PASS：parallelRows(两排同向 se 上下相邻)=全 [se]、真拐角 L(横 se+竖 sw)=corner[se,sw]/横臂[se]/竖臂[sw]、rowEW=[se,se,se]、rowNS=[sw,sw,sw]、afterRemove=[se](auto 自愈)、eastNeighbor(45,45)=[se](原生不翻面)。406 资源 404 仅 favicon，无 JS 错误。

## 修正墙体补墙触发方向（用户 ABC 菱形边澄清）
- **用户澄清**：之前说的"A格的ne和B格的sw重合"中的 ne/sw 指的是**菱形地格上的边**（四边的几何重合），**不是四边缘墙**。B 是 A 的右上(屏幕上右)格、C 是 A 的左下(屏幕左下)格。

  - 原生 `se`(东臂) → 仅当【**东邻(gx+1,gy)**原生是 `sw`】才补 `sw`（水平连续墙）。
  - 原生 `sw`(南臂) → 仅当【**北邻(gx,gy-1)**原生是 `se`】才补 `se`（竖直连续墙）。
  - 反向(南邻 se / 西邻 sw)不补 → 避免把邻居墙方向延长成 T 形（正是用户 ABC 场景1 禁止的）。
